# Bank Loan Risk Analysis

Проект по анализу кредитного портфеля банка с использованием PostgreSQL и SQL. Данные загружены напрямую в PostgreSQL и обработаны средствами SQL (очистка, проверка качества данных, аналитика).
В проекте выполнены очистка данных, исследовательский анализ, сегментация клиентов по кредитному риску и создание аналитических представлений (Views). Результаты визуализированы в виде интерактивного дашборда.

## Цели проекта

- Очистить исходный набор данных о банковских кредитах.
- Проанализировать структуру кредитного портфеля и клиентской базы.
- Выявить факторы, влияющие на просрочки и дефолты по кредитам.
- Провести сегментацию клиентов по уровню кредитного риска.
- Закрепить навыки работы с SQL в PostgreSQL, включая оконные функции и CTE.
- Создать проект для портфолио Data Analyst.

## Датасет

В проекте используется открытый датасет **Bank Loan Status Dataset** (Kaggle), содержащий данные о выданных банком кредитах и их текущем статусе.

Основные поля датасета:

- Loan ID — идентификатор кредита;
- Customer ID — идентификатор клиента (у части клиентов несколько кредитов);
- Loan Status — статус кредита (Fully Paid / Charged Off);
- Current Loan Amount — сумма кредита;
- Term — срок кредита;
- Credit Score — кредитный рейтинг клиента;
- Annual Income — годовой доход;
- Years in current job — стаж на текущем месте работы;
- Home Ownership — тип владения жильём;
- Purpose — цель кредита;
- Monthly Debt — ежемесячные долговые обязательства;
- Years of Credit History — длина кредитной истории;
- Months since last delinquent — месяцев с последней просрочки;
- Number of Open Accounts — количество открытых счетов;
- Number of Credit Problems — количество кредитных проблем;
- Current Credit Balance — текущий баланс задолженности;
- Maximum Open Credit — максимальный открытый кредитный лимит;
- Bankruptcies — количество банкротств;
- Tax Liens — налоговые залоги.

Перед анализом данные были очищены:

- удалены дубликаты по Loan ID;
- обработаны некорректные значения Credit Score (выбросы за пределами допустимого диапазона);
- обработаны пропуски в ключевых полях;
- приведены типы данных.

## Основные этапы анализа

### 1. Создание базы данных

- Создание таблицы `loans` для хранения данных о кредитах.
- Настройка структуры таблицы в PostgreSQL.

### 2. Подготовка данных

- Импорт исходного файла через pgAdmin.
- Проверка соответствия колонок и типов данных.

### 3. Проверка качества и очистка данных

- Поиск пропусков (NULL) по каждой колонке.
- Поиск дубликатов по Loan ID.
- Выявление и обработка аномальных значений (например, некорректный Credit Score).
- Создание очищенного аналитического представления.

### 4. Исследовательский анализ

- Анализ структуры кредитного портфеля (суммы, сроки, статусы).
- Анализ клиентской базы (доход, стаж, тип жилья).
- Анализ по целям кредита (Purpose).
- Распределение кредитов по статусу Fully Paid / Charged Off.

### 5. Анализ рисков и просрочек

- Связь Credit Score со статусом кредита.
- Влияние долговой нагрузки (Monthly Debt / Annual Income) на дефолт.
- Анализ клиентов с историей просрочек (Months since last delinquent).

### 6. Продвинутый SQL

- Common Table Expressions (CTE).
- Оконные функции: `LAG`/`LEAD` для сравнения кредитов одного клиента, `ROW_NUMBER()` для определения первого/последнего кредита, `RANK()`/`NTILE()` для сегментации по кредитному скорингу, накопительные суммы задолженности.
- Представления (Views).

### 7. Сегментация по кредитному риску

- Расчёт риск-показателей на основе Credit Score и долговой нагрузки.
- Присвоение сегментов риска (Low Risk / Medium Risk / High Risk).
- Профилирование сегментов по ключевым метрикам.

### 8. Финальные аналитические запросы

- Структура портфеля по статусам и целям кредита.
- Топ факторов риска дефолта.
- Профиль клиентов по риск-сегментам.
- Динамика повторных кредитов клиентов.

- Общая сумма выданных кредитов
- Количество кредитов и клиентов

- Распределение по целям кредита
- Распределение по типу жилья

### Страница 2 — Риск-анализ

Содержит аналитику по рискам:

- Распределение клиентов по риск-сегментам
- Связь Credit Score и статуса кредита
- Топ факторов, влияющих на просрочку
- Профиль клиентов высокого риска
